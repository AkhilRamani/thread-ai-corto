# Brief wave

`brief-wave.webp` is generated decorative artwork based on the user-approved Design Systems Surf wave reference. The image contains no text. It was generated specifically for this project, then converted to WebP at quality 90 with Sharp.

The source screenshots and approved composition are under `docs/design/`. A CSS contrast scrim sits above the image and below the live HTML text. The static texture intentionally avoids continuous GPU animation and supports reduced motion without a second rendering path.
